# えんがわポスト

札幌すごいAIハッカソン 2026夏 — テーマ「顔を知る、たった一人の悩みを突き刺せ」

## テーマ解釈

対象はマスユーザーではなく「顔を知っている、実在のたった一人」— 作者自身と、その祖母。

作者(北海道在住)の悩みは二層になっている:

1. 昨年祖父を亡くした岐阜の祖母に想いを伝えたい。でも**言葉にすると涙が出て、電話ではうまく話せない**(言葉の重さ)
2. そもそも**連絡を送ろうとすること自体が億劫**で、一歩が出ない(腰の重さ)

祖母側の制約: スマホを持っていない。テレビ電話は「同期・言葉必須」で、この悩みには合わない。

**えんがわポスト**は、非同期・言葉不要の第3の手段。①はAIとの対話による「咀嚼」で、②はAI側から口火を切る「きっかけ」機能と30秒で送れる体験で刺す。

## 仕組み

```
[孫側 /]                                [祖母側 /grandma.html または スタックチャン]
 きっかけをもらう(AIが口火を切る)
 心情をAIと対話(音声入力可)
   → Claude(サーバ経由)が傾聴・咀嚼
   → お便り3案を生成、選んで手直し
   → 顔写真を添えて POST /api/letter ──→  GET /api/letter をポーリング
                                          大きな文字で表示+音声読み上げ
       GET /api/reply ←────────────────  ワンボタンで「顔だけのお返事」
```

- サーバ: **依存ゼロのNode.js**(server.js)。静的配信+Claudeプロキシ+お便りAPI
- 対話・咀嚼: Claude API(キーはサーバ側のみ。未設定ならモックで全機能動作)
- 音声入力: Web Speech API / 読み上げ: speechSynthesis
- 顔: getUserMedia + canvas
- 物理端末(スタックチャン)は `GET /api/letter` をポーリングして読み上げるだけで参加できる

## 「顔から読み取る」

言葉ゼロの入口。今の顔写真をClaude(vision)に見せると、見えた雰囲気をそっと伝えて質問で口火を切ってくれる。撮った顔はそのままお便りに添付される。「顔を知る」の直球実装。

## スタックチャン(物理の受信面)

`stackchan/engawa_stackchan/engawa_stackchan.ino` をArduino IDEで書き込む(必要ライブラリ: M5Unified のみ)。

1. Macで `ipconfig getifaddr en0` してIPを確認
2. スケッチ冒頭の WIFI_SSID / WIFI_PASS / SERVER_URL を書き換え(MacとM5は同じWi-Fiに。会場Wi-Fiが端末間通信を塞ぐ場合はスマホのテザリングに両方つなぐのが確実)
3. 書き込むと、お便り着信時にチャイム→口パクしながら本文表示。ボタンAでもう一度

サーバ側は `GET /api/letter/plain` を叩いているだけ。受信面は差し替え可能という設計の実証。

## 起動

```bash
cd app
ANTHROPIC_API_KEY=sk-xxx node server.js   # キー無しでもモックで動く
```

- 書く側: http://localhost:8787/
- 祖母側: http://localhost:8787/grandma.html (別ウィンドウで。「はじめる」を押す)

カメラ・マイクは localhost のみ許可。Chrome推奨。

## 設計メモ(n=1という思想)

- プロンプト内の祖母のペルソナは意図的にハードコード。汎用サービスではなく「たった一人」のための道具であり、**n=1に最適化すること自体がテーマの回収**。
- 2時間で確実に動かすため依存ゼロを選択(npm installなし、`node server.js`のみ)。
- スタックチャンは「出口の一つ」。芯(きっかけ→対話→咀嚼→お便り)はWebで完結し、物理端末は差し替え可能な受信面。
